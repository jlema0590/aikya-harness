# Ansible automation
1. Inspect existing roles, inventory grouping, variables and playbooks.
2. Require least privilege, idempotent task design and protected Vault credentials.
3. Validate syntax locally where tools are already available; do not execute playbooks against remote hosts without separate approval.
4. Document approved changes, rollback, executed checks and security risks.
5. Write Aikya living docs under aikya/docs/ in the selected en/es language only.
