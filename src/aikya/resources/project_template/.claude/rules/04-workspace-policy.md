# Workspace policy

Use the current project checkout for ordinary changes. A new branch can be created
there when requested; it does not authorize creating a worktree. Create or enter
a new worktree only when the user explicitly requests one for this task. Never
select `isolation: worktree` for a subagent automatically. Preserve existing
worktrees and the user’s unrelated changes.

The workspace hook requests host permission for recognized worktree creation.
It is not a sandbox for arbitrary external shell scripts or terminal sessions.
