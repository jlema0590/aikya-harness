## Root causes and reproduction

Historical command fixtures under tests/fixtures/command-renames were not covered
by the byte-preserving attributes used for signed/pinned resources. Native Windows
checkout converted LF to CRLF. The exact migration hash no longer matched, so
retirement correctly preserved the unknown command. An actual Git checkout-index
test with core.autocrlf=true and core.eol=crlf reproduced the byte mismatch locally.

The installer test assumed three PreToolUse groups before the new workspace guard.
A canonical temporary path produces four: the user hook, Bash guard, skill observer
and workspace guard. On macOS, the unresolved /var temporary alias contains a
symlink ancestor, so conservative workspace registration was skipped and the stale
count passed. Resolving the fixture root reproduced the same 3 != 4 failure locally.

## Corrections

Preserve command-fixture bytes through .gitattributes and extend the existing real
Git conversion regression to that path. Do not normalize unknown command content
or relax the migration catalog's hashes.

Use the resolved temporary root in the installer test. Assert byte-identical
settings across repeated installation, preservation of the user hook/permissions,
unique registered commands and exactly one workspace guard. Avoid a hard-coded
total that changes when an intentional hook is added.

Keep version 7.2.2 because these are corrections to the same unreleased PR. Runtime
behavior, model calls and the current user's installations are unchanged. Full
regression and native CI reruns are required; their current results are recorded
in the validation report and PR checks.
