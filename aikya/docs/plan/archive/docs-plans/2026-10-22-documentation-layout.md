- Testing plans belong in plan/testing.md.
- Generate indice.md from actual existing Markdown files; do not list nonexistent placeholders.
- Existing-project analysis creates only pages supported by observed/configured data. Architecture and overview provide actual profile/module evidence; do not invent missing application behavior.
- skill-comparison.md is written only after an explicit external-skill installation command, never during onboarding, plan or status. Preserve /aikya-skills-install and support requested alias /aikya-install-skill.
- Preserve customized documents and runtime files. Managed legacy paths are migrated with backups and a preview; customized collisions block instead of overwriting. Read-only analysis never migrates or indexes.
- Engineering documentation remains English; existing en/es living-doc policy is preserved.
