## Bounded independent review

One independent read-only review found a reproducible ordering defect: setup could
retire a verified old command before discovering that its replacement directory
was a symlink. A regression reproduced it in global and project scopes.
Replacement destinations are now checked before writes; retirement runs after
registration and validates replacement availability before retiring any command
in the batch. The regression and full suites passed after this correction.

Custom commands are never retired solely because they contain a managed marker
or match a copied unverified modern runtime file. Source hashes establish ownership;
unknown edits remain active with an explicit review notice. This means a customized
installation may retain an old command until the developer resolves it.
