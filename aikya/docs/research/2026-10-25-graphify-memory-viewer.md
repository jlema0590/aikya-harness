## Existing Aikya integration and sources

- `src/aikya/catalogs/external.py` already lists Graphify and implements `install_graphify()`. The explicitly authorized external-skill installation can install the CLI and register its project skill. Its own note says index generation happens on demand, not during installation.
- `src/aikya/resources/commands/aikya-install-skill/SKILL.md` and `README.md` currently describe this optional integration. A subsequent developer decision replaces named presets with user-selected generic installation; the [transition plan](../plan/2026-10-25-skills-a-eleccion-del-usuario.es.md) supersedes the earlier recommendation to retain preset integration. `/aikya-memory` must neither install nor invoke it.
- `src/aikya/memory/knowledge.py` owns note validation, review, identity binding, expiry and recall. Actual kinds are `user`, `feedback`, `project` and `reference`; review states are `pending`, `approved` and `rejected`. Reuse these contracts rather than assigning new kinds or granting approvals in the viewer.
- `src/aikya/memory/store.py` defaults project notes to `aikya/docs/memory/` and separately supports private notes outside the checkout. The proposed viewer exports only this project's records; it does not enumerate private stores.
- The incremental code index remains planned, not implemented. A first viewer can display notes and documentation without claiming that code symbols have already been indexed.
- `src/aikya/cli/commands.py` currently declares 27 public commands. The requested `/aikya-memory` will be the 28th when implemented, registered and tested.

## Scope decision

Implement a first-party read model over existing project notes, explicit documentation links and the planned code index. Export a local snapshot, not another authoritative graph database. Do not create a Graphify wrapper, vector store, cloud account, transcript collector or automatic background process.

The companion [implementation plan](../plan/2026-10-25-aikya-memory-html.es.md) defines paths, data contracts, command behavior, limitations and acceptance tests. This review and that plan do not implement the command.
